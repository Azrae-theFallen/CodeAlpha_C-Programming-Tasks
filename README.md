Code Alpha Internship

This repository contains the programming tasks assigned during the CodeAlpha C Programming Internship.

Project Tasks:

[TASK 1] Basic Calculator Program
* **Objective:** Write a C program to perform basic arithmetic operations.
* **Operations:** Addition, Subtraction, Multiplication, and Division.
* **Implementation:** Developed using `switch case` for operation selection and logic to handle division by zero.

 [TASK 2] Matrix Operations
* **Objective:** Implement matrix calculations using functions and 2D arrays.
* **Operations Included:**
    * Matrix Addition
    * Matrix Multiplication
    * Matrix Transpose

[TASK 3] Student Management System
* **Objective:** Create a menu-driven program to manage student records.
* **Features:** Add, Delete, Update, Search, and Display records.
* **Technical Implementation:** Utilizes `structures` and `file handling` for permanent data storage.

 [TASK 4] Banking System (Mini Project)
* **Objective:** Build a Bank Account Management System.
* **Functions Included:**
    * Deposit
    * Withdraw
    * Balance Enquiry
* **Technical Implementation:** Developed using `functions`, `structures`, and `file handling`.
